Support

Bring the useful details.
We’ll find the right path.

DealDrop support is designed around the listing, match, notification, or subscription detail that needs attention.

REPORT / REVIEW / RESOLVE?

How to contact support

Use the path inside the app.

The repository does not contain a confirmed public support email or service URL, so this site intentionally does not invent one.

01
Profile → SupportOpen the reviewed support destination from the DealDrop app when it is configured.
02
Listing → Report a listing problemUse the structured report for a broken or incorrect listing.

If the configured support service is unavailable, keep the listing ID and request ID visible in the app, then retry later. Do not send credentials through an unconfigured channel.

Listing reports

Report the thing that is wrong.

From listing details, use “Report a listing problem” and choose the closest category. DealDrop currently supports:

↗Broken linkThe destination no longer opens.
$Wrong priceThe displayed price does not match.
◷Stale listingThe listing may no longer be current.
≠Incorrect matchThe result does not fit the watchlist.
□Missing imageThe listing image is unavailable.
…OtherSomething else needs a review.

Safe diagnostic context

Helpful detail, not private credentials.

Safe to include

  • DealDrop listing ID
  • Marketplace name shown in the app
  • Report category
  • App version
  • Request ID, if the app shows one
  • Relevant watchlist or match ID

Never include

  • Passwords or sign-in codes
  • Push tokens or access tokens
  • Payment details
  • Private credentials
  • Seller contact data
  • Raw provider payloads or authorization headers

Billing and access

Subscriptions stay with the store.

01

Premium trial

DealDrop includes a 7-day free trial. Continued access after the trial requires an active premium subscription; there is no free tier.

02

Restore a purchase

Sign in to the same DealDrop account, open the premium screen, and use “Restore purchases.” Store and RevenueCat account identity must match before access can be restored.

03

Manage or cancel

Use the subscription-management controls provided by Apple or Google. The store shows the current product price, renewal period, and cancellation details.

Account deletion

Ready to leave? Delete from Profile.

In the app, open Profile → Delete account and confirm. The live account, profile, watchlists, matches, notifications, push tokens, favorites, feedback, product events, and related reports are removed through the account-deletion flow. Historical backup images may persist until the provider’s backup window expires.

If you cannot sign in, use the configured support destination once it is available. Do not send a password or payment details while asking for help.
