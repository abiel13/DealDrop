# DealDrop Iteration 4 Issues

Iteration 4 is the production-readiness and product-usefulness pass identified during the app audit.

The issues are ordered so that launch blockers are handled before additional marketplace coverage:

1. [Make weekly summary reachable and links actionable](01-weekly-summary-navigation.md) — P0
2. [Production premium access and billing readiness](02-production-premium-billing.md) — P0
3. [Production worker deployment, health, and observability](03-production-worker-operations.md) — P0
4. [API security and abuse protection](04-api-security-hardening.md) — P0
5. [Native push notification release readiness](05-native-push-release-readiness.md) — P0
6. [Production data governance, backups, and legal readiness](06-production-data-governance.md) — P0
7. [Watchlist details, saved listings, and history navigation](07-watchlist-detail-and-history.md) — P1
8. [Match explainability and marketplace monitoring health](08-match-explainability-and-source-health.md) — P1
9. [Listing freshness and unavailable-listing lifecycle](09-listing-freshness-lifecycle.md) — P1
10. [First-use onboarding and activation](10-first-use-onboarding.md) — P1
11. [Support and listing problem reports](11-support-and-reporting.md) — P1
12. [Accessibility and poor-network resilience](12-accessibility-and-network-resilience.md) — P1
13. [Marketplace expansion validation](13-marketplace-expansion-validation.md) — P2

Marketplace expansion is intentionally last. The current code already contains eBay, Etsy, Rakuten, and StockX adapters; the next source should be selected using target-audience demand, permitted access, and measurable usefulness rather than adapter count.
